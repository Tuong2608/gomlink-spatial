Privacy Policy — GomLink Spatial

Product: GomLink Spatial — Quick Link Collector for AI Agents (for Microsoft Edge)
Publisher: Jun_268 (Tuong2608)
Effective Date: November 13, 2026  |  Last Updated: November 13, 2026

Summary: GomLink Spatial operates strictly locally inside Microsoft Edge and optionally on your own computer via 127.0.0.1. We do not collect, track, transmit, sell, or share any personal information or browsing data with external servers or third parties.

1. Overview

GomLink Spatial — Quick Link Collector for AI Agents ("GomLink Spatial", "the Extension") is an open-source extension built for Microsoft Edge. Your saved links and browsing context remain entirely under your control on your own device.

2. Information Accessed and Stored

GomLink Spatial accesses only the minimal data required to perform user-initiated link saving:

  • Web Page URL and Title (User-Initiated Only): When you explicitly click the extension toolbar icon, press the shortcut (Alt+S), click Save Current Tab inside the popup, or choose the save action from the Microsoft Edge context menu, the Extension reads the active tab's or selected link's URL and title. Internal browser URLs (such as edge://, about:, and view-source:) are ignored and never stored. General browsing history is never monitored or logged.
  • Local Extension Storage (storage.local): Your saved Markdown link list and local sync timestamp token (clear_token) are stored strictly in Microsoft Edge's local extension storage (chrome.storage.local).
  • Optional Localhost Bridge (http://127.0.0.1:18999): If you choose to run the optional open-source Python bridge server (bridge_server.py) on your own computer, the Extension communicates strictly with http://127.0.0.1:18999 (loopback address only — traffic never leaves your device) to synchronize saved links into local Markdown files (inbox_links.md and da_doc_links.md). If the local bridge is not running, the Extension works completely offline inside Microsoft Edge local storage.

3. Microsoft Edge Permissions Explained

Permission Purpose
tabs Reads the active tab's URL and title strictly when you initiate a save action, and triggers local badge/storage sync when switching tabs.
storage Saves your collected links and local sync state inside Microsoft Edge local extension storage.
contextMenus Provides right-click menu shortcuts in Microsoft Edge (open notebook, clear notebook, save link or page).
alarms Periodically triggers lightweight synchronization between Microsoft Edge local storage and your optional localhost bridge (127.0.0.1:18999).
host_permissions
(http://127.0.0.1:18999/*)		 Strictly limited to your local device's loopback address (127.0.0.1) for optional local file sync. No external websites or remote servers are accessed.

4. Data Sharing, Analytics, and Third Parties

  • No External Servers: GomLink Spatial does not connect to any remote server operated by the developer or any third party.
  • No Tracking or Advertising: The Extension contains zero analytics, telemetry, fingerprinting, advertising scripts, or third-party trackers.
  • No Sale or Sharing: We never sell, rent, or disclose your information to third parties.

5. User Controls, Access, and Data Deletion

You retain full ownership and control over all stored data in Microsoft Edge:

  • View, Edit, and Export: Right-click the Extension icon in Microsoft Edge and select Open Notebook to view cards, switch to Raw Markdown editing, or copy your links at any time.
  • Delete Specific Links or Clear All: Remove individual link cards, click Clear inside the popup, or use the right-click toolbar context menu to clear the entire list immediately.
  • Manage Optional Local Files: Stop bridge_server.py at any time to stop local file sync, and delete inbox_links.md, da_doc_links.md, or sync_state.json from your disk whenever you wish.
  • Uninstall Removal: Removing GomLink Spatial from Microsoft Edge (edge://extensions) permanently erases all extension storage data.

6. Updates to This Privacy Policy

This Privacy Policy is kept up to date with the functionality of GomLink Spatial. Any material changes to how data is accessed, stored, or controlled in Microsoft Edge will be reflected on this page with a revised "Last Updated" date prior to releasing an updated extension version.
